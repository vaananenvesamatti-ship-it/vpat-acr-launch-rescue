# VPAT / ACR Launch Rescue - early access validation page

Static, zero-dependency pages used to measure genuine interest in a proposed one-time
EUR 99 tool for software vendors asked for a VPAT / Accessibility Conformance Report.

**The product does not exist yet. No payment is taken.** Nothing here is a certification,
a legal opinion, or a compliance guarantee.

- index.html - the offer page
- need-vpat.html - a free, neutral decision tool; several branches conclude you do NOT
  need a VPAT, or should hire a specialist rather than buy anything from us
- demo.html - five-criterion demonstration of the claim/evidence mechanism

Everything runs in the browser. No accounts, no uploads, no server, no trackers.
